Kamu Punya Pertanyaan?

Bagaimana cara order di Dykojoki.id?
Caranya sangat mudah!
1. Tentukan Game dan Layanannya.
2. Masukkan User ID, Zone ID, dan Nickname Anda dengan teliti.
3. Pilih Nominal atau Tab Mode joki (Tersedia versi ECERAN dan PAKET).
4. Pilih Metode Pembayaran (E-Wallet/Bank).
5. Masukkan No. Whatsapp dan pilih wilayah negara Anda (+62/dll).
6. Klik "Beli Sekarang". Tagihan serta Invoice Anda akan langsung masuk secara otomatis melalui WhatsApp Admin Dykojoki!
Metode Pembayaran apa saja yang ada di Dykojoki.id?
Dykojoki.id menyediakan rute pembayaran termudah untuk Indonesia maupun Mancanegara. Saat ini tersedia dompet digital E-Wallet (DANA, GoPay, OVO) demi proses instan. Kami juga melayani Transfer Antar Bank secara manual (BCA & Mandiri) via verifikasi Customer Service kami yang responsif 24/7.
Berapa lama pesanan saya diproses?
Untuk pesanan Top Up (Diamond/UC dll), proses berjalan kilat dalam 1-10 detik karena terhubung langsung ke server pusat (API). Untuk jasa Joki, estimasi standar adalah 1x24 Jam per 10 Bintang/Level.
Apakah Top Up & Joki di sini aman dari banned?
Sangat aman! Layanan Top Up kami menggunakan distributor legal 100% (*No Carding*), dan proses Joki murni dimainkan oleh tangan manusia (*Pro Player*) tanpa *cheat* atau bot pihak ketiga. Akun Anda bergaransi Anti-Banned seumur hidup seputar transaksi dengan kami.
Apakah saya harus memberikan password akun?
HANYA untuk layanan Jasa Joki kami memerlukan akses login sementara. Sedangkan untuk pesanan Top Up, Anda sama sekali tidak perlu memberikan password (cukup ketik ID Player/Zone ID Saja). Privasi orderan dijamin oleh hukum.
Kenapa pesanan saya belum berubah statusnya?
Biasanya, pesanan diproses sukses dalam 1-5 menit. Jika terjadi *delay* (keterlambatan), kemungkinan besar karena antrean server *game* pusat sedang padat atau *Payment Gateway* sedang melakukan pemeliharaan (*maintenance*). Anda selalu dapat memantaunya menggunakan ID Invoice di halaman "Cek Pesanan".
Bagaimana kebijakan pengembalian dana (Refund)?
Jika sistem mendeteksi kegagalan transaksional pada API produk kami (seperti stok habis massal) lebih dari 1x24 Jam, dana Anda akan kami otomatis kembalikan (Full Refund 100%) ke dompet digital (E-Wallet) / rekening bank yang Anda gunakan sebagai sumber pembayaran, tanpa potongan apapun.
