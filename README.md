A responsive gaming storefront for top-up and boosting services, designed for Mobile Legends, PUBG Mobile, Free Fire, Genshin Impact, and Roblox.

## ✨ Highlights

- Fast game top-up and boosting services
- Promos, featured games, and product catalogs
- Testimonials and FAQ customer section
- Dark/light mode toggle
- Payment, calculator, and privacy pages

## 🧩 Main Features

- Modern gaming-themed interface
- Mobile-friendly responsive layout
- Easy-to-browse game categories
- Promo slider and featured content
- Customer support section
- User review forms and interactions

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Google Fonts

## 📁 Project Structure

- `index.html` — main landing page
- `payment.html` — payment and order page
- `calculator.html` — calculator page
- `preview.html` — preview page
- `terms.html` — terms and privacy page
- `index.css` — main styling
- `script.js` — interactive logic and mock data
- `assets/` — image and icon assets

## ▶️ How to Run

Open `index.html` directly in the browser, or start a local server:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```
