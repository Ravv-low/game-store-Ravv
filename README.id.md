Landing page responsif untuk platform top up game dan jasa joki dengan tampilan modern untuk Mobile Legends, PUBG Mobile, Free Fire, Genshin Impact, dan Roblox.

## ✨ Highlights

- Top up game dan layanan boosting
- Promo banner dan katalog game populer
- Form testimoni dan FAQ pelanggan
- Toggle tema gelap/terang
- Halaman pembayaran, kalkulator, dan syarat penggunaan

## 🧩 Fitur Utama

- Antarmuka bertema game modern
- Layout responsif untuk desktop dan mobile
- Kategori game yang mudah dibrowse
- Slider promo dan konten unggulan
- Layanan dukungan pelanggan
- Ulasan pengguna dan interaksi form

## 🛠️ Teknologi

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Google Fonts

## 📁 Struktur Proyek

- `index.html` — halaman utama
- `payment.html` — halaman pembayaran dan pesanan
- `calculator.html` — halaman kalkulator
- `preview.html` — halaman preview
- `terms.html` — halaman syarat & privasi
- `index.css` — styling utama
- `script.js` — logika interaksi dan data game mock
- `assets/` — aset gambar dan ikon

## ▶️ Cara Menjalankan

Buka file `index.html` langsung di browser, atau jalankan server lokal:

```bash
python -m http.server 8000
```

Lalu buka:

```text
http://localhost:8000
```
